# TaxiScanner

Pixel-faithful responsive clone of the TaxiScanner web landing design, built with Next.js 14 (App Router), Tailwind CSS, Lucide icons, and lightweight Shadcn-style UI primitives.

## Stack

- Next.js 14 + TypeScript
- Tailwind CSS
- Lucide React
- Plus Jakarta Sans

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

- `src/app` — App Router entry (`page.tsx`, layout, styles)
- `src/components` — Landing sections + UI primitives
- `src/lib` — Shared utils + mock data
- `public/images` — Assets extracted from the Figma prototype

## Design notes

Brand primary blue is `#197DF1`. Hero, Why Choose, Operators CTA, and testimonial avatars use the same imagery from the Figma file.
